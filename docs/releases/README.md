# Release notes

One file per version uploaded to Google Play, named after `versionName`
(e.g. `1.0.0.md`). Each file holds the exact "what's new" copy pasted into
Play Console for that release, so the repo always has a record of what
testers/users were told changed.

See [`CHANGELOG.md`](../../CHANGELOG.md) at the repo root for the full,
developer-facing history (every change, not just user-facing copy).
